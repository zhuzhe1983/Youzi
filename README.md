# 柚子 · Youzi

**一个给自己用的本地 AI 工作台，仅面向苹果 M 系列芯片笔记本。**

柚子是我通过 **vibe coding** 持续打磨的个人项目。出发点很简单：
把自己常用的本地 AI 能力放进一个顺手的桌面应用，先满足自己的需求，
再顺带开源分享给有相似需求的人。

**自用为主，顺带分享；不做任何商业收费和推广。**
不是商业产品，也不追求堆功能或跑分排名。比起“功能最多”，我更在意日常使用是否自然、
设置是否清楚，以及模型、任务和文件能不能管理得明白。

工作台与交互体验受到 **WorkBuddy** 的启发，底层推理、模型管理和 API 服务技术主要基于
**Rapid-MLX** 继续改造。感谢这两个项目带来的灵感和技术积累。

## 适合什么设备

| 项目 | 柚子的目标与建议 |
| --- | --- |
| 设备 | **仅针对苹果 M 系列芯片笔记本**，即 Apple Silicon MacBook Air / MacBook Pro |
| 系统 | macOS 14 或更新版本（当前桌面工程的最低部署版本） |
| 内存起点 | **最低推荐 24GB 统一内存** |
| 更推荐的配置 | **64GB 及以上统一内存** |
| 其他平台 | 不以 Intel Mac、Windows、Linux 或其他设备为适配和验证目标 |

这些是使用建议，**不是模型运行保证**。24GB 不代表可以运行所有模型，
也不代表聊天、语音、图片和视频模型可以同时全部加载。
实际内存需求取决于模型体积、量化方式、上下文长度和同时运行的任务；
系统和其他应用也需要预留空间。模型文件可能很大，下载前也请留意磁盘余量。

## 想解决什么问题

柚子的方向不是把底层引擎的所有开关搬到界面上，而是围绕日常使用组织功能：

| 方向 | 希望带来的体验 |
| --- | --- |
| 聊天与任务 | 让日常对话、历史任务和工作空间衔接起来，减少来回找入口 |
| 专家、技能与连接器 | 按需选择和启用能力，让常用技能更容易找到和复用 |
| 我的文件 | 按类型整理任务产出的文档、图片和视频，方便查找和预览 |
| 本地多模态 | 统一管理聊天、语音、图片和视频模型，按设备资源与模型支持情况使用 |
| 模型服务 | 让自己的脚本和其他应用，也能通过兼容 API 使用本地正在运行的模型 |
| 个性化与设置 | 把称呼、回复偏好、等待提示、字体、外观和安全选项放在清楚的位置 |

### 当前状态

**项目仍在持续迭代，以上是产品方向，不是公开版本的完整验收清单。**
本地开发版、仓库主分支和发布包可能暂时不同步；多模态能力、模型并行运行和 API
兼容范围，都应以对应版本的实际实现与验证结果为准。

不承诺所有模型都能运行、所有第三方客户端都兼容，也不承诺固定的更新频率或修复时限。
如果你也想尝试，建议先从一个合适大小的聊天模型开始，再逐步添加其他能力。

### 从源码检查桌面工程

需要兼容 Swift 6 的 Xcode / Command Line Tools；完整应用还依赖 Python 模型运行时。

```bash
git clone https://github.com/zhuzhe1983/Youzi.git
cd Youzi
swift build --package-path apps/rapid-mac -c release
```

这条命令只编译 Swift 工程，**不等于打包完整应用，也不包含模型权重**。
完整应用打包入口为 [`apps/rapid-mac/scripts/build.sh`](apps/rapid-mac/scripts/build.sh)，
请先阅读其中的运行时、资源和签名要求。部分工程、命令和产物名称仍保留上游命名，
不要把名称迁移与已完成的功能适配混为一谈。

## 隐私与使用边界

- **本地推理不等于所有操作都离线。** 模型下载、联网搜索、外部连接器、MCP 服务，
  以及自行配置的远程接口都可能访问网络。请按需启用并确认目标服务的数据处理方式。
- **模型服务默认用于自己的本机工作流。** 不要把未鉴权的服务直接暴露到公网；
  API Key、个人对话和私有文件不要放进公开 Issue、日志或截图。
- **模型会出错。** 执行文件修改、调用外部服务或处理重要资料前，请确认操作内容，
  为重要数据保留备份。
