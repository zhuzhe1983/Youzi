# 柚子 · Youzi

**给自己用的本地 AI 工作台，仅面向苹果 M 系列芯片笔记本。**

柚子是一个通过 **vibe coding** 持续打磨的个人项目：先解决自己的使用需求，
顺带把代码分享出来，供有相似需求的人尝试、交流和修改。
**不做任何商业收费和推广**，也不承诺商业产品级的稳定性、更新频率或技术支持。

交互与工作台体验受到 **WorkBuddy** 的启发，底层本地推理和模型服务技术主要来自
**Rapid-MLX**。感谢两个项目带来的灵感和技术积累。

## 适用设备与内存建议

| 项目 | 项目定位 / 建议 |
| --- | --- |
| 设备 | **仅针对苹果 M 系列芯片笔记本**，即搭载 Apple Silicon 的 MacBook Air / MacBook Pro |
| 系统 | macOS 14 或更新版本（当前桌面工程的最低部署版本） |
| 内存起点 | **最低推荐 24GB 统一内存** |
| 更推荐的配置 | **64GB 及以上统一内存** |
| 其他平台 | 不以 Intel Mac、Windows、Linux 或其他设备为适配和验证目标 |

这些是柚子的使用建议，不是模型运行保证。**24GB 不代表可以运行所有模型，
也不代表可以同时加载聊天、图片、语音和视频模型。** 实际需求取决于模型体积、
量化方式、上下文长度、任务类型，以及同时加载的模型数量；系统和其他应用也需要内存。
下载模型前请检查模型自身的要求，并预留足够的磁盘空间。

## 想做成什么

柚子的方向是把本地模型能力整理成一个更顺手的个人工作台，而不是复制一个商业产品：

- **日常聊天与任务**：减少来回切换页面，让对话、任务和产出文件更容易找到。
- **专家、技能与连接器**：把常用能力组织起来，按需启用，而不是堆叠入口。
- **本地多模态**：逐步整合聊天、语音、图片和视频模型的管理与调用。
- **模型服务**：让本地应用和脚本能够通过兼容 API 使用已运行的模型。
- **个性化与设置**：围绕实际使用习惯持续优化，不为了功能数量而增加复杂度。

项目仍在迭代中，以上是产品方向，不代表每项能力都已在公开版本中完成或验证。
本地开发版、仓库主分支和发布包可能暂时不同步，请以对应版本的代码和说明为准。

### 从源码检查桌面工程

需要兼容 Swift 6 的 Xcode / Command Line Tools；完整应用还依赖 Python 模型运行时。

```bash
git clone https://github.com/zhuzhe1983/Youzi.git
cd Youzi
swift build --package-path apps/rapid-mac -c release
```

上述命令只构建 Swift 工程，**不等于完整可分发的应用**，也不包含模型权重。
完整应用打包入口为 [`apps/rapid-mac/scripts/build.sh`](apps/rapid-mac/scripts/build.sh)；
请先阅读脚本中的运行时、签名和资源要求。部分工程、命令和产物名称仍保留上游命名，
这是兼容与迁移过程的一部分。

## 隐私与使用边界

本地推理是项目的主要方向，但“本地 AI”不等于所有操作都离线。
模型下载、联网搜索、外部连接器、MCP 服务或用户配置的远程接口可能访问网络。
请按需启用，并自行确认目标服务的数据处理方式。

不要将未鉴权的模型服务直接暴露到公网，也不要在 Issue、日志或截图中提交 API Key、
个人对话、私有文件或其他敏感信息。模型输出可能出错，执行文件修改或其他重要操作前请确认。
