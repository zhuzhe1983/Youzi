# 设置说明开关

设置窗口右上角提供“显示说明”开关，默认关闭。打开后显示各页的介绍、选项解释和普通使用提示；再次关闭即收起。选择即时生效，跨页面共享，并在重新打开应用后保留，无需点击“保存设置”。

开关只控制说明文字。字段名称、输入框、按钮、字数统计、当前状态、报错、密钥授权入口，以及确认对话框中的内容始终可见。已有设置值和运行中的任务不受影响。

实现统一使用 `settingsShowsExplanations` 环境值。设置窗口读取 `youzi.settings.showExplanations.v1`，默认 `false`；共用标题和设置行据此显示副标题与描述，独立说明段落使用 `settingsExplanation()`。这些共用组件在设置窗口以外默认保留文字。新设置页沿用这套方式，不按字体或颜色批量隐藏内容，避免误隐藏错误、统计和模型状态。

## 工具、技能与连接的位置

主界面“专家·技能·连接”集中提供四个标签：专家、技能、内置工具、连接。技能是任务方法与指令；搜索、浏览、天气、模型查询和生成等直接执行的能力属于内置工具，其开关继续使用原有配置与执行拦截逻辑。连接标签提供实际 MCP 服务的添加、编辑、启停、工具与授权管理。

设置中的“智能体”改为“联网搜索”，只保留搜索服务和 API Key。浏览与 MCP 审批仍由安全中心管理；其中“管理连接器”跳到主界面的连接标签。旧搜索设置深链继续有效。

原连接页只填写名称与说明的新增表单已移除，避免把登记条目误当成服务已经配置。已有任务连接条目原样保留并单独展示，真正的 MCP 服务由移入的配置面板管理；此 UI 调整没有删除用户记录或运行服务。
