# 聊天中的语音通话

语音入口在现有输入框旁。打开后，通话控件显示在输入框上方，聊天记录和文字输入保持可见。点击“开始通话”才会开启麦克风。

通话中显示听取、识别、思考、朗读状态、时长和输入音量；支持静音、打断和挂断。静音会丢弃尚未提交的语音片段，取消静音后重新听取。切换聊天、模型，退出页面或应用进入后台会结束通话。

“通话详情”收纳当前模型、音频错误码和兼容模式。系统回声消除无法启动时，可以明确选择“兼容模式重试”：柚子朗读期间暂停听取，点击“打断并继续说”后再开口。不会自动关闭回声消除后继续录音。麦克风权限和音频设备错误分别提示。

本机日志确认原故障为 AVAudioEngine 的 VoiceProcessing I/O 初始化错误 -10875（kAudioUnitErr_FailedInitialization），并非已确认的权限拒绝。兼容模式避开该系统音频单元；硬件组合是否恢复仍需实际通话验证。

## 验证

`RAPID_DESKTOP_NO_PORT_SWEEP=1 YOUZI_VOICE_RENDER=1 swift test --package-path apps/rapid-mac --filter 'YouziLive|YouziInlineVoice|LiveVoice'`

67 项测试通过，覆盖生命周期、静音片段清理、错误分类、兼容模式选择、取消、审批交接和音频分段。浅色/深色、空闲/错误四张原生视图渲染已检查。测试使用隔离音频替身，不代表实际麦克风与扬声器的通话验收。音频速度、音高和节奏不作调整。
