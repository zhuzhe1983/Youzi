# 统一模型列表

设置 → 模型 → 模型加载按聊天、音频、图片、视频分场景。音频中的语音识别和语音合成各自选择优先模型。

一个列表同时显示已下载的本地模型和已配置的远程模型，并标注来源、状态和唯一的“优先”模型。远程模型可从行内菜单编辑或移除；停用的远程模型可启用并设为优先。无需再分别设置加载策略、来源优先级和远程首选。

- 优先模型用于 GUI 的默认调用。当前任务里已经明确选择的模型不会被改掉；新任务或“自动选择”采用新选择。
- 选择本地优先模型时尝试加载它，下次打开 Youzi 也会加载。没有选为优先的本地模型可手动加载。
- 选择远程模型不加载本地权重。切换优先模型不会卸载已加载模型、取消请求或改变进行中的任务。
- 加载失败或优先模型不可用时明确提示，不因失败自动切换模型或服务商。
- 状态统一使用“已加载／未加载”；远程显示“已配置／已停用”，避免把远程配置当作本地权重。

对外模型服务是附加功能，仍在单独的“模型服务”页配置。它提供所有实际已加载的本地模型，包括手动加载的非优先模型；不提供远程模型，也不另设一份默认模型。

模型文件页先显示场景切换、搜索筛选和模型列表，文件目录、关联模型和存储概览放在后面。

聊天中的图片、语音、视频工具沿用同一优先选择。已配置的远程模型不需要本地服务；客户端使用已有的远程协议适配器。远程图片保留请求尺寸，不套用本地的 16 像素对齐，也不发送本地专用采样参数。

## 旧设置兼容

旧配置只读解析成一个有效优先选择：沿用旧来源顺序，旧本地自动加载清单取第一项。原始设置保留，首次更改优先模型后在远程模型文档的可选 `preferredModels` 字段中保存各场景的统一选择。语音识别和语音合成的选择互不影响。明确清除或丢失的选择不会重新启用旧自动加载清单。
