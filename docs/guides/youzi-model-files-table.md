# 柚子模型文件表格

“设置 → 模型 → 模型文件”按聊天、语音、图片、视频分类，使用原生
`NSTableView` 管理模型；目录设置和链接外部文件的能力保持不变。

## 查找与排序

- 搜索模型名、系列和仓库，多个关键词同时匹配。
- 状态、系列、量化、仅推荐、仅完整速质指标等筛选取交集。
- 点击列头排序，也可用“排序”菜单；支持调整列宽、拖动列、键盘选择、
  横向和纵向滚动。模型、状态和操作列靠左，其余指标可横向查看。
- 使用现有硬件推荐策略，聊天分类最多两款推荐模型置顶，其后是收藏模型，
  再应用所选排序。置顶不会绕过搜索或筛选，也不会制造重复行。
- 缺失数值显示 `—`，升序和降序都排在有数值的模型之后。

## 指标口径

| 指标 | 含义 |
| --- | --- |
| 文件大小 | 优先显示磁盘报告；未下载模型仅在参数规模和量化明确时估算权重大小，用 `≈` 标记。不是运行时内存。 |
| 参数规模 / 量化 | 解析模型别名或仓库中的明确标识；未知值不默认当成 4 bit。MoE 使用总参数量。 |
| 准确度 | 现有目录收录的通识推理分数；悬停可见其来源。 |
| 综合质量 | 通识推理、代码、工具调用、指令遵循四项百分制分数等权平均，缺项不计算。 |
| 速度 | 目录收录的 tok/s；悬停查看记录的硬件/测试来源，不是当前机器测速。 |
| 性价比 · 速质 | `综合质量 / 100 × tok/s`。这是质量修正的吞吐量，不是金钱或内存性价比，也不是本机性能预测。 |

不同硬件和测试条件的结果只能参考，不应据此宣称本机绝对性能。
图片、语音、视频模型不套用聊天基准；没有适用记录时保持空缺。
本次没有修改基准数据或推荐模型名单。

## 操作与保护

- 未下载：下载 / 失败后重试。下载中：进度与取消。
- 已下载：加载；已加载或加载中不重复发起。
- 当前聊天服务可用时，沿用已有多模型驻留加载入口，不主动停止其他模型。
- 没有聊天服务时可从聊天模型启动服务；媒体模型提示先启动聊天服务。
- 删除必须确认。外部链接、驻留、加载中的模型禁用删除，并在实际执行前
  再检查驻留状态。不为删除某个模型隐式停止整个服务。
- 搜索、筛选、排序和渲染不触发下载、加载、删除或启动策略变更。

## 场景选择弹窗

删除解释勾选/默认模型的长段文字。“更多模型设置…”位于场景分段控件右侧，
仍按当前聊天/图片/语音/视频分类跳转。大字号时弹窗等比例增宽，保持一行。
自动加载策略、模型调用路由、服务 API 均未在本次改动中调整。

## 验证与回滚

在 macOS / Apple Silicon、Swift 6.3.3 环境：

```sh
RAPID_DESKTOP_NO_PORT_SWEEP=1 \
YOUZI_MODEL_TABLE_RENDER=1 \
swift test --package-path apps/rapid-mac -c release \
  --filter 'YouziModelTable|ModelSurfaceRedesign|ModelCacheActions|YouziScenarioModels|ExternalModelCatalog|SettingsVisualFoundation|SettingsEnvironmentInjection'
```

渲染测试使用独立偏好域和合成模型，不下载、加载或删除真实模型。
设置 `YOUZI_MODEL_TABLE_RENDER_DIR` 可指定 PNG 输出位置。
可选 `YOUZI_MODEL_TABLE_WINDOW_CAPTURE=1` 在已具备屏幕录制权限时捕获测试窗口；
不会请求权限，也不会捕获其他窗口。位图缓存可能遗漏原生菜单的合成层，
完整控件外观应以窗口截图或实际客户端为准。

回滚只需重新打开先前验证的完整本地应用包；不要替换签名包中的单个文件，
不要重置模型目录或用户偏好。本变更没有数据迁移。
