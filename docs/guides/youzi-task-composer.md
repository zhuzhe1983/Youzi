# 新建任务与对话输入区

参考 WorkBuddy 的实际交互，将新任务页分为欢迎语、场景入口、输入区和示例提示。场景只切换示例，不发送请求、不加载模型，也不自动启用某项能力。点示例会填入草稿；有文字时追加一行，保留用户输入。

「＋」统一提供文件、专家、技能与连接器引用入口。专家显示在输入区底部，可切换或取消；技能和连接器显示为可移除的标签。延续已有的 `@专家 /技能 #连接器` 请求引用方式，发送时一起带入请求。选择引用不代表授予权限、连接成功或已经执行技能。专家和技能 ID 同步至任务元数据，窗口草稿保存引用选择。

底部保留当前模型名称及状态球、上下文占用、发送/停止和语音。工作空间与项目移到输入框下方，便于确认文件归属。能力管理仍通过「专家·技能·连接」主页面进入。对话中使用紧凑输入区；新任务显示场景与示例。

验证：ComposerControls、SimpleWorkbench、SidebarLayout 等 4 suites / 20 tests passed。还需随完整应用打包做原生窗口验收。没有新增专家团队调度或连接器授权流程。
