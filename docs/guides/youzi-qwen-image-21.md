# Qwen-Image 2.1 默认图片推荐

Youzi 的图片模型推荐改为 `qwen-image-2.1`，使用
`mlx-community/Qwen-Image-2.1-mflux-q4`，下载约 8.9 GiB。
去噪模型和文字编码器均为原生 MLX 4-bit 权重，固定版本为
`746a58556820933a2df5c75887a2570f1ad200c0`，运行库为 mflux 0.20.0。

「设置 → 模型 → 模型文件 → 图片」将它置顶为首选推荐。
图片工作区没有已选模型、也没有自动加载池配置时，优先选择已下载的
Qwen-Image 2.1；尚未下载时继续优先使用其他已下载模型。
已有的明确选择和自动加载池不会因推荐变动而被覆盖。
推荐本身不会触发下载或自动加载。

默认生成和图生图均为 40 步。支持 `/v1/images/generations` 和
`/v1/images/edits`；后者接受一张参考图，使用 img2img 条件生成，
不代表接入了另一个指令编辑模型。另提供 `qwen-image-2.1-bf16`
作为更高精度选项，但它不是默认推荐。

模型会在去噪前释放文字编码器，并在每次生成后释放去噪模型。
连续请求会按需重新加载，不能把磁盘文件大小等同于常驻内存。
推荐面向 Youzi 原有的 24GB 及以上设备范围；未在 8GB/16GB Mac 上验证。

## 下载与使用

```sh
rapid-mlx pull qwen-image-2.1
rapid-mlx serve qwen-image-2.1
```

下载检查同时识别传统的仓库内 blob 和 Hugging Face 的
`hub/blobs/<两位哈希前缀>/<完整 SHA-256>` 共享缓存。
其他指向仓库外的文件链接仍会被拒绝。

## 验证记录（2026-10-19）

本机为 Apple M5 Max、128GB 统一内存。真实离线生成使用上述固定权重、
512×512、40 步、seed 42，得到有效 PNG；一次运行耗时 55.24 秒，
MLX 分配器峰值 5.457 GiB。图像已目视检查。这是单次功能验收，
不代表稳定吞吐或整个进程内存，也没有停掉同时运行的聊天服务。

后端验证覆盖模型分派、q4 编码器检查、下载完整性、连续请求、图生图、
40 步默认值、内存估算及原有图片模型。桌面验证覆盖目录、推荐优先级、
生成进度和运行库打包。
