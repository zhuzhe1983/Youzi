# 成果生成信息与重新生成

成果卡片的信息按钮、文件菜单和图片／视频预览顶部都可打开“生成信息”。详情显示生成时的模型名称、模型 ID、服务器、提示词，以及请求参数、实际提交参数和服务返回参数。未记录的字段明确显示“未记录”，不会用当前设置冒充历史配置。

新图片、语音、视频工具成果在保存文件时同时保存生成记录。历史成果按原任务的工具调用 ID 和 artifact_id 对应恢复提示词及已记录参数；不会按文件名猜测，不会把其他任务的记录套用过来。历史远程地址没有保存时保持未知，禁用无法确认原服务的 reroll。

“重新生成”直接调用原多媒体工具，保留原任务归属，另存新成果并记录原成果 ID。模型、服务器和提示词不变；本地图片、视频更换随机种子，远程随机性由服务商控制。语音沿用记录的音色、语速，不对音频做拉伸或变速处理。未记录的历史默认参数使用当前默认值，详情中会说明。已停用、删除或改变地址／模型 ID 的远程配置不会被静默替换；本地模型未加载时沿用原加载确认流程。正在执行时重复点击不会重复提交，可以停止等待。

## 文件内嵌

- PNG：UTF-8 `iTXt` 块，关键字 `YouziGeneration`。
- WAV：RIFF 自定义 `yzgn` 块，UTF-8 JSON。
- MP4：专用 UUID 扩展 box，UTF-8 JSON。保持所有原媒体位置，已有元信息更新时将旧专用 box 标为 free。

元信息不包含 API Key、鉴权头或端点查询参数。图片像素、PCM 数据和视频媒体数据保持原样，不使用编解码器。导出复制原文件，因此保留元信息。第三方播放器不一定会显示 Youzi 的自定义字段，但会忽略不认识的扩展块。PNG 使用 [W3C iTXt 格式](https://www.w3.org/TR/png-3/#11iTXt)，WAV 遵循 [RIFF 长度和偶数字节填充规则](https://learn.microsoft.com/en-us/windows/win32/directshow/avi-riff-file-reference)，MP4 遵循 [atom 长度边界](https://developer.apple.com/documentation/quicktime-file-format/atoms)。

旧成果的详情提供“写入文件”，只修改应用托管文件，写入失败保留原始文件。历史恢复不会在启动时自动改写旧文件。对于不支持或不合法的容器，生成仍保存原始内容和成果记录，元信息写入失败明确显示；不会为了附加元信息重新编码媒体。

元信息采用版本 1；未知版本和超过 256 KiB 的记录被拒绝读取。此版本提供成果内查看，不把任意外部文件的元信息自动执行为工具调用。

## 验证

Swift 回归 344 tests / 55 suites 通过；最终详情布局调整后，8 项专项测试再次通过。覆盖元信息往返、旧格式兼容、历史关联、导出保持、媒体字节保持、原服务限制及重复提交抑制。原生安装验收与语音面板更新一同进行。
