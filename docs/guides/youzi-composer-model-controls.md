# 聊天输入栏与模型可用状态

## 输入栏

- 简约聊天中的发送、停止和语音入口使用相同的 28pt 圆形按钮、44pt 点击区域。
  发送和停止占用同一位置；语音在最右侧。打开语音面板本身不会启用麦克风。
- 删除重复的「已在本机就绪」标签。模型入口变为可点击的球，仍打开场景模型列表。
- 球面等分当前可用场景：聊天蓝色、图片黄色、语音绿色、视频紫色。
  没有可用场景时为灰色。这不是内存比例图；内存分布继续保留在弹层下方。
- 可用性只看当前选择的模型；未明确选择时复用既有自动加载池及本地/远程优先级。
  已下载、配置过、同类型其他模型已加载，都不意味着当前模型已就绪。
- 语音识别/语音合成共享一个绿色扇区，任意一项可用即可显示；悬停和辅助功能
  会明确列出可用子能力。这不意味着全双工链路的所有组件都已经就绪。

## 模型列表

- 本地与远程模型放在同一个列表中；删除重复的优先级入口和远程分组标题。
  优先级配置仍在设置中，不改变其路由或持久化策略。
- 本地设备图标及内存数字的绿色表示已加载；勾只表示当前场景选中。
  未加载时显示磁盘大小，不把磁盘大小冒充实时内存。
- 远程保留网络图标，右侧显示在线/离线，检测中或尚未验证单独标识。
- 顶部入口名为「模型设置」，按当前场景跳到对应设置页。
- 切换本地媒体模型成功后也更新对应选择，不再只更新聊天别名。
  保留既有加载确认、共存保护和忙碌状态限制，不隐式卸载其他模型。

## 状态检查边界

本地状态来自运行时 residency 接口；界面活跃时每 5 秒刷新，失败时不沿用
旧的绿色状态。既有加载逻辑与公共服务协议未改变。

远程只读探测使用保存的**对应提供方凭据**请求模型列表，并要求其中包含精确的
模型 ID；不调用生成、不复用本地 bearer、不写用户设置、不跟随重定向。
无模型列表或列表缺少模型的提供方无法验证在线，即使其生成接口可能可用。
「在线」表示近期的列表连通及身份验证通过，不保证未来生成成功。

检查只覆盖当前使用的远程模型及打开弹层后当前场景的远程行。60 秒缓存，
单轮最多并行 3 项，资源超时 8 秒，响应上限沿用 discovery 的 4 MiB。
视图退出/应用后台取消结构化检查；设置修改使旧结果失效，手动刷新可以重查。
网络异常和鉴权失败不会在 UI 或日志中泄露 URL、API key 或原始响应。
