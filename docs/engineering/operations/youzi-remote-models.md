# 柚子远程模型（可选补充）

开发分支：`atlas/youzi-remote-models`，2026-09-09。
默认仍使用本地模型；不需要远程服务时，无需配置，不改变原来的本地流程。
本功能不是把远程服务商接入柚子对外的 API 代理。

## 添加与管理

1. 打开「设置 → 模型 → 模型服务」，滚动到底部。
2. 展开「远程模型（可选）」并点「添加远程模型」。各场景设置页底部也有入口。
3. 填写显示名称、场景、Base URL 和模型 ID。Base URL 示例：
   `https://provider.example/v1`。只填域名时会补 `/v1`，自定义网关前缀会保留；
   不要填写 `/chat/completions` 这样的完整接口地址，不在地址中填写密钥。
4. API Key 可留空以使用免认证服务；非空时作为 Bearer 使用并存入本机钥匙串。
   不会复用柚子本地 API 的密钥。HTTP 需要明确勾选允许明文传输，只用于可信网络。
5. 「读取模型列表 / 测试连接」只发起 `GET /models`，不发送聊天或生成内容。
   服务商不支持模型列表时仍可手动填写模型 ID。连接成功不等于验证了每种生成能力。
6. 按服务商实际能力填写图片理解/编辑、音色、视频参考图、尺寸和秒数，然后保存。
   同一服务商可以添加多个模型；一个模型支持多种场景时可分别添加对应配置。

列表支持编辑、启用/停用、设为该场景的远程首选，以及移除配置。
移除会删除本地配置与对应钥匙串项目，**不会删除服务商的模型或文件**。
编辑时默认保留已有密钥；勾选替换并留空表示清除认证。更换地址后必须明确填写新
密钥或选择空密钥，测试连接也不能把旧地址的密钥偷偷带到新地址。

## 来源优先级

- 「模型服务」底部设置全局 **本地优先（推荐） / 远程优先**。
- 聊天、音频、图片、视频子页可选择 **跟随全局 / 本地优先 / 远程优先**。
- 音频的识别和合成共享音频优先级，但各自选择可用的远程首选模型。
- 优先级**即时保存**；远程编辑框中的内容则在点击「保存」后生效。
- 自动选择会复用原有的本地自动加载池/推荐逻辑，再按来源优先级选择候选。
  首选来源没有候选时，才考虑另一来源。明确选定的模型始终优先。
- 修改优先级不更换现有的聊天/媒体模型。要立即重新选模，在模型菜单中选择
  「按当前优先级选择」。这是一次选择操作，不是持续跟踪设置的后台模式。
- 远程候选位于模型菜单的次级区域，标为「远程」，没有下载、加载或内存占用数字。
  不进入本地模型文件表格，也不会把已常驻的本地模型卸载掉。
- **不是失败重试策略**。超时、鉴权、配额或生成错误不会自动把请求交给另一家服务。
  停用/移除已选模型会要求重新选择，不悄悄改变数据接收方。

## 当前实现范围

| 场景 | 远程请求 | 说明 |
| --- | --- | --- |
| 聊天 | `/chat/completions`，SSE | 支持现有文本、工具调用解析及显式启用的图片输入；不是 `/responses` 适配器 |
| 语音识别 | `/audio/transcriptions` | multipart 上传；识别上下文用标准 `prompt` 字段 |
| 语音合成 | `/audio/speech` | 使用配置的音色，请求 WAV；不探测本地专用 voices 接口 |
| 图片 | `/images/generations`，可选 `/images/edits` | 支持 base64 或受限公共 HTTPS 图片地址；编辑需服务商支持 |
| 视频 | `/videos` 及任务查询/内容/删除 | 使用配置的尺寸/时长，不伪装为自动发现的能力；生成仍可能收费 |

图片默认不指定 `response_format`，也可选 `b64_json` 以匹配需要该字段的服务商。
服务商返回的图片地址不能指向局域网/本机；局域网网关可以直接返回 base64。
图片 URL 下载不携带 API Key，并限制 32 MiB；发现列表限制 4 MiB。
其他生成响应和视频内容没有统一字节上限，不要接入不信任的服务。

视频需要显式连接。连接后固定该会话的地址与密钥，已有任务查询不受配置编辑影响。
任务运行时不能切换/重新连接；停用配置会禁止新生成，但已有任务仍可查询。
空闲后通过模型菜单「重新连接（应用最新配置）」切到保存后的地址和密钥。
远程视频删除会删除服务商上的对应视频及本地预览，界面会单独确认；不是撤销计费。
取消远程图片的客户端等待也不保证服务商已经停止生成。

**保持本地范围的入口：**实时语音对话、内置模型管理/多模态工具，以及柚子对外的
`/v1` 服务不会自动路由到新配置的远程提供方。远程聊天可以使用原有授权的工具流程，
但不是把本地工具的权限扩大成任意远程生成权限。

## 隐私与费用

远程调用会发送本次请求所需内容，可能包含聊天历史、记忆、附件、授权工具结果。
新增配置、手动选择或远程优先都应理解为允许相应场景使用远程服务。
远程轮次不额外发起自动标题、后续建议和记忆提取请求，避免隐藏的远程推理费用。
服务商协议差异、配额、账号权限、模型参数和真实生成质量仍需使用自己的服务验证。

## 开发验证

所有测试使用临时 UserDefaults、假钥匙串和模拟网络，不读用户密钥、不调用收费模型。

```sh
RAPID_DESKTOP_NO_PORT_SWEEP=1 YOUZI_REMOTE_VISUAL_QA=1 \
  swift test --package-path apps/rapid-mac -j 6 \
  --filter 'RemoteModel|ChatStream|AudioClient|ImageClient|Video|ModelReadiness|ModelSelection|ModelPicker|YouziResident|YouziScenario|SettingsEnvironment|SettingsDeepLink|YouziCompact'
```

本任务已通过 378 个测试、41 个 suite。包含视频地址/密钥固定、停用阻断新请求、
完成后的重新连接，以及中英文的折叠/展开入口和五类编辑界面渲染。
临时 PNG 位于系统临时目录 `youzi-remote-visual-qa`，不写入用户聊天/配置或仓库。
截图需要固定 NSHostingView 的 frame/sizingOptions 并提供不透明背景，避免把 intrinsic
高度与透明底误判成 UI 溢出。界面使用同一套真实 SwiftUI 控件，数据为合成样例。

尚未以用户真实服务商验证生成，也没有完整 GUI 点击到收费服务的端到端验收。
HTTP 重定向拒绝策略尚无真实重定向服务器集成用例；单元 transport 不模拟跳转。

## 本地构建与回退

- 只在本任务 worktree 构建。所有构建/测试/启动带 `RAPID_DESKTOP_NO_PORT_SWEEP=1`。
- 保留正在运行的旧客户端，不扫描端口、不批量杀进程、不覆盖其他 worktree 的 app。
- 本次不合并 main、不发布 release；未完成的记忆整合分支不在本任务范围内。
- 回退 UI/客户端时使用保留的上一候选 app，不需要删除模型、聊天或记忆数据。
- 旧客户端忽略新增远程配置。再次启用新客户端时配置仍保留；不应靠清空全部偏好回退。
