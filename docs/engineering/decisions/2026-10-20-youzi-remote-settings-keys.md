# 远程模型密钥保存在 Youzi 设置中

负责人：Atlas；设置界面协作：Pixel。本机执行。用户明确要求远程模型 API Key 使用 Youzi 自己的设置存储，取消钥匙串授权流程。

## 存储与读取

聊天、ASR、TTS、图片和视频的远程模型统一使用应用的 UserDefaults 设置域。每个模型对应 `youzi.models.remote.apiKey.v1.<UUID>`，与 URL、模型名称等元数据分开存放。记录包含 API Key 或明确的免认证状态，不再向 Keychain 写入远程密钥，也没有交互式钥匙串读取入口。

此处是应用设置中的普通持久化数据，不宣称经过应用级加密。密钥不进入模型目录、成果元信息、诊断日志或远程模型元数据文档。设置备份可能包含这些密钥。搜索服务等其他功能的存储不属于本次远程模型变更。

复用服务器时，从 Youzi 设置读取源模型密钥并保存到新模型自己的记录。只允许相同规范化 Base URL；更改服务器仍需明确替换或清空密钥。源模型删除不影响已复制的记录。显式清空或删除会保留无密钥标记，避免恢复旧元数据时重新导入旧密钥。

## 旧配置迁移

只对已有模型且尚无新存储记录的条目，尝试一次禁止系统弹窗的旧钥匙串读取。成功时保存到 Youzi 设置；原来无密钥的条目保持免认证；读取失败则记录“需要重新填写”，保留模型与服务器配置。后续启动和调用均读取新记录，不反复探测钥匙串，不把读取失败当成免认证请求。

重新填写通过远程模型编辑页的“替换 API Key”完成。用户也可明确留空，选择免认证。旧钥匙串条目暂不删除，供回退恢复；新版本完成迁移后不再使用它们。取消旧版“授权读取密钥并重试”按钮及其交互式访问实现。

## 验证与回退

`RemoteModelSettingsSecretsTests` 使用隔离设置域和模拟旧存储，验证五类模型保存/重新打开、只迁移一次、不可访问密钥的显式失败、服务器复用、清空/删除防止旧密钥恢复、损坏数据保留与替换，以及新建免认证模型完全不访问旧存储。已有远程客户端协议与搜索设置测试继续运行。

本机交付前备份完整应用和设置。回退到旧应用时，使用交付前的设置与旧钥匙串；新版本中后续新增或修改的密钥不会自动回写到旧钥匙串。发布的 0.14.5 文件保持原样，本次为带源码标识的本机修复版。
