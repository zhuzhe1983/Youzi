# Youzi 0.14.6

这一版改进了设置界面、远程密钥保存和长时间使用时的稳定性，并修复了工具调用、音频上传与图片请求中的兼容问题。

- **设置更简洁。** “显示说明”默认关闭，可随时打开，选择会保留；字段、错误和重要状态始终可见。专家、技能、内置工具与 MCP 连接集中到主界面管理，原有配置继续保留。
- **远程密钥直接保存在 Youzi 设置中。** 聊天、语音识别、语音合成、图片和视频使用同一套保存方式。旧密钥只尝试迁移一次；无法读取时保留模型配置并提示重新填写，不再反复弹出钥匙串授权。
- **减少内存持续占用。** 单请求完成后及时释放 KV 缓存；达到内存限制时先尝试回收无引用数据，并提供与实际原因一致的错误说明。
- **多模态生成更可控。** `seed`、`top_k` 和 `min_p` 正确传递到采样器。检测到持续重复输出时停止生成、释放对应批次，并保留已有回答。
- **工具调用更可靠。** 改进现有模型的原生工具格式识别、必选工具处理及流式输出；没有提供工具时不再误把普通文字解析成调用。达到输出长度限制时正确报告截断，避免把未完成的调用标记为正常完成。
- **音频上传保留格式信息。** 转写、翻译和强制对齐保留 WebM、M4A、Ogg 等文件的容器提示，区分文件损坏与解码环境故障，不改变原音频的语速、节奏或音高。
- **图片参数错误更早反馈。** 无效图片请求在加载模型权重前返回明确错误，减少无效等待。
- **聊天记录更完整。** 中断后已经生成的回复继续显示；切换聊天后，原会话的标题仍能正常更新。私有存储文件从创建时起即限制为当前用户可读写。

## 安装与限制

适用于 macOS 14 或更新版本的 Apple Silicon Mac，包含完整推理运行环境，不包含模型权重。建议至少 24 GB 内存，较大模型需要更多内存。本包使用临时签名（ad-hoc），未经 Apple 公证。应用与推理运行时版本均为 0.14.6，应用构建号为 176。

远程模型 API Key 保存在应用设置中，不作应用级加密；设置备份可能包含这些密钥。无法迁移的旧密钥需要在远程模型编辑页重新填写，新版本中的密钥更改不会自动回写到旧钥匙串。

本次保留现有推理依赖和模型范围，主要回移已确认的修复，不包含新的模型支持或性能提升承诺。语音设备、远程服务和大模型仍受原有能力与资源限制。
