# Youzi 0.14.5

这一版集中整理了模型设置、任务创作和语音对话。

- **统一模型列表。** 本地与远程模型按聊天、音频、图片、视频放在同一列表，每个场景选择一个优先模型。本地优先项自动加载，其余可手动加载。对外 API 提供所有已加载的本地模型，远程配置仍服务于 GUI。
- **模型设置更直接。** 模型文件、模型加载、模型服务分别管理；“添加模型”放到搜索框右侧，本地入口直达对应分类。复用服务器配置只沿用地址、密钥和连接选项。未下载的文件不再显示无效的删除按钮。
- **成果保留生成信息。** 可查看模型、服务器、提示词及请求、实际提交、返回参数；再次生成（reroll）沿用原模型与参数并更换种子，原成果保留。新生成的 PNG、WAV、MP4 会尽可能内嵌元信息，支持格式的旧成果也可手动写入。旧记录缺失的字段明确显示未知。
- **语音融入聊天。** 通话控件显示在输入框上方，保留聊天记录和文字输入。加入静音、状态和时长；系统回声消除启动失败时可选择兼容模式重试，权限与设备错误分别提示。
- **创作体验改进。** 本地图片推荐 Qwen-Image 2.1，开放采样参数，不支持的尺寸会调整到邻近可用值并告知。远程模型发现支持多场景筛选、显式选取和 CLIProxyAPI 视频适配；任务创建布局、成果预览与可恢复删除也得到整理。
- **启动与打包修复。** 远程密钥不可访问时明确报错，避免启动界面一直等待；图片依赖固定到已验证版本。

## 安装与限制

适用于 Apple Silicon Mac，包含完整推理运行环境，不包含模型权重。建议至少 24 GB 内存，较大模型建议 64 GB 或更多。本包使用临时签名，未经 Apple 公证。

远程模型列表的候选识别不等于服务商生成接口验证。再次生成会创建新文件，远程调用可能计费；模型、服务器不可用时不会静默换用其他来源。历史记录没有保存的参数无法准确补齐。

兼容语音模式在柚子朗读时暂停听取；实际回声消除能力取决于音频设备和系统。此版本保留原音频语速、节奏和音高。Wan/LTX 等视频模型仍可能在生成时加载权重；请求帧数与输出帧数可能因模型时间填充而有差异。
